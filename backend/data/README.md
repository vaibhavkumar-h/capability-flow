# Market data included

These files are the processed/derived outputs supplied by the second teammate's Capability Flow analytics package:

- `analytics_jobs.csv` — 15,841 analytics job postings.
- `jobs_exploded.csv` — exploded skill mentions from those postings.
- `top_skills_demand.csv` — top market skill demand summary.
- `capability_flow.csv` — five-skill capability-vs-demand integration.
- `seniority_skill_analysis.csv` — junior/mid/senior skill demand.
- `jds_results.csv` — JDS skill/outcome summary.
- `sds_results.csv` — SDS trait/outcome summary.
- `datascience_jobs.csv` — data-science job/salary dataset.

The frontend labels these as market context. They are not treated as an individual's real-time capability.

Source/methodology details are preserved in the teammate package's approach/report materials.
